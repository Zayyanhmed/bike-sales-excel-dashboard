# Bike Sales & Customer Insights Dashboard

![Bike Sales Dashboard](dashboard.png)

## Project Overview

This project transforms a dataset containing 1,000 customer records into an interactive Excel dashboard designed to analyse bike purchasing behaviour and customer demographics.

The analysis explores relationships between bike purchases, income, gender, age groups and commute distance.

## Objectives

- Analyse customer purchasing behaviour
- Compare income between bike purchasers and non-purchasers
- Analyse purchasing patterns across age groups
- Explore the relationship between commute distance and bike purchases
- Create an interactive dashboard for customer segmentation

## Data Preparation

The dataset was cleaned and prepared in Microsoft Excel.

A calculated age-bracket field was created to group customers into:

- Adolescent
- Middle age
- Old

## Analysis

PivotTables and PivotCharts were used to analyse:

- Average income by gender and bike purchase status
- Bike purchases across age groups
- Bike purchases by commute distance

## Interactive Dashboard

The dashboard includes slicers for:

- Marital Status
- Region
- Education

These allow users to dynamically filter the analysis and explore different customer segments.
